# Wildfront

Round-based team PvP with Old School RuneScape-style 600 ms tick combat and Call of Duty 4-style
progression (create-a-class, challenges, kill streaks, prestige). Built in **Godot 4.7 (GDScript)**.
The design source of truth is [`docs/GDD.md`](docs/GDD.md). Decisions made while building are logged in
[`docs/DECISIONS.md`](docs/DECISIONS.md).

## Run it

1. Open Godot 4.7 → **Import** → pick `project.godot` in this folder → **Import & Edit**.
2. Press **F5** (Run Project).

From a terminal (`G` = path to your Godot exe, e.g. `F:\Godot\exe\Godot_v4.7.2-stable_win64.exe`):

```
G --path .                                   # play
G --headless --path . --script res://tests/run_tests.gd     # unit tests (exit code 0 = pass)
G --headless --path . --script res://tools/balance_sim.gd -- duels=20 matches=2   # balance simulator
```

## How to play

Main menu → **Play vs bots** → pick a mode, map, playlist, class and bot difficulty → **Find match**.
Use the short countdown option in **Options** if 15 s feels long while testing.

| Action | Control |
| --- | --- |
| Walk / attack | Left-click ground / enemy (right-click for an OSRS-style menu) |
| Camera | Arrow keys or middle-mouse drag to rotate, mouse wheel to zoom |
| Side panel tabs | F1 Inventory, F2 Equipment, F3 Prayer, F4 Magic, F5 Combat |
| Protection wards | 1 Blades (melee), 2 Arrows (ranged), 3 Spells (magic) |
| Offensive prayers | 4 (best unlocked set for your current weapon) |
| Special attack | E (or click the spec orb / Combat tab) |
| Eat | Q (or click food in the inventory) |
| Gear-switch hotkeys | Z melee, X ranged, C magic (toggle in Options) |
| Run | R (or click the run orb) |
| Perk abilities | T Rebuke, Y Snare Trap |
| Kill streaks | 5 Scrying Orb, 6 Meteor Strike (then click a tile), 7 Summoned Guardian |
| Quick chat | 8 / 9 / 0 |
| Scoreboard | hold Tab |
| Ready up (pre-match) | Space |
| Menu / cancel targeting | Esc |

Spells: with a staff equipped, clicking a spell sets **autocast**. Without one, click a spell then an enemy to
cast it once (e.g. the Battlemage's scimitar + Root combo). Equips and eating resolve on the next tick, so a
whole gear switch is several quick clicks inside one 0.6 s tick, as in OSRS.

**LAN multiplayer:** one player picks the match settings on the Play screen, then **LAN multiplayer → Host game**.
Others enter the host's IP and press **Join**. The host presses **Start match**. Humans are split across teams and
bots fill the rest. The port is 24600 (UDP); allow it through Windows Firewall on the host.

## Project layout

```
data/      all content as JSON: items, spells, prayers, perks, levels, unlocks, classes, modes, maps, challenges, rules
shared/    game rules used by server and client: Sim (tick loop), Combat formulas, MapGrid (BFS + LOS),
           Loadout, Progression (XP/levels/unlocks), Challenges, ModeRules, Specials, DB (data loader + validation)
server/    MatchServerCore (owns the Sim + bots), MatchServer (600 ms clock), BotBrain (bot AI)
net/       NetSession (ENet LAN host/join, RPCs), RemoteLink (client view of a remote server)
client/    main.gd (menus <-> match), profile (save file), ui/ (theme, icons, orbs, minimap, menus),
           match/ (3D world, characters, HUD, input)
tests/     unit tests (run_tests.gd runs every suite)
tools/     balance_sim.gd (bot-vs-bot win rates and match pacing), debug_duel.gd (tick trace of one duel)
docs/      GDD.md, ASSETS.md, DECISIONS.md
art/       Blender generators, palette source, manual overrides, previews (not imported by Godot)
assets/    generated models, palette texture + material, animation library
```

The server is authoritative: the client only sends intents (`move`, `attack`, `use`, `prayer`, `spec`, …) and
draws the snapshot it receives each tick. All tuning lives in `data/*.json`, so balance changes are data edits.

Your profile (XP, classes, challenges, settings) is saved to `%APPDATA%\Godot\app_userdata\Wildfront\profile.json`.

## Art pipeline

Models and animations are generated by code (see [`docs/ASSETS.md`](docs/ASSETS.md)). Tool paths are in
`art/tools.json`.

```
python tools/build_assets.py                     # rebuild everything: palette, Blender models + clips, Godot import, checks
python tools/build_assets.py --only bronze_scimitar
python tools/build_assets.py check               # coverage, naming, triangle budgets, required clips
python tools/build_assets.py shots char:melee:1 --sheet          # screenshots into art/previews/
python tools/build_assets.py shots base_body --anims walk,run,attack_slash
G --path . res://tools/dev/asset_viewer.tscn     # interactive asset viewer
G --path . res://tools/dev/map_shots.tscn -- --maps frostgate_ruins   # map screenshot sheets (art/previews/map_*.png)
```

Maps are dressed from their gameplay data (see [`docs/ENVIRONMENT.md`](docs/ENVIRONMENT.md)): environment models
live in `art/blender/env/`, the layout rules in `client/match/env/env_layout.gd`, and `tests/test_environment.gd`
checks that the art never contradicts the map's blocking tiles.

Recolour the whole game by painting `assets/palette/palette.png` (16 x 16 swatch cells, names in
`assets/palette/palette.json`). Put a hand-made `art/manual/<asset-id>.blend` to override any generated model.

## Dev flags

Pass after `--` on the command line: `--autoplay=<mode>` (start a match at once), `--autofight` (your character
attacks the nearest enemy), `--timescale=N`, `--screenshot=<png> --shot-delay=<s>`, `--menu=play|barracks|options|editor`,
`--lan-host` / `--lan-join=<ip>` / `--name=<n>`, `--trace` (prints tick and network logs), `--map=<id>` (with
`--autoplay`), `--perf` (prints fps, draw calls and primitives every 5 s), `--placeholder-map` (old box map art).
